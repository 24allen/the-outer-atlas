# 界外档案 / THE OUTER ATLAS

**BEYOND THE KNOWN WORLD**

公元2089年，第七远征队穿越南极深处的环极冰幕。黑色海洋、倒悬群岛、低语森林和远古巨构逐渐显露。人类熟悉的世界，也许只是巨大未知体系中的一个角落。

这是一个原创虚构世界探索网页，结合巨构主义场景、连续滚动叙事和可操作的远征工具。所有地理、文明与档案均为虚构创作。

## 在线游玩

发布完成后的入口：**https://24allen.github.io/the-outer-atlas/**

部署成功前，这个地址只是预定地址。发布后，朋友无需登录 GitHub、安装软件或运行本地服务器，使用现代浏览器即可体验。

## 怎么玩

- 向下滚动推进探索；反向滚动返回，右侧刻度或目录可直接选择章节。
- 点击每章的探索按钮，使用对应工具：按住扫描、地图拖动缩放、探灯、调谐无线电、海面声呐、轨道校准、回声监听、碑文解锁与静止观测。
- 完成观测后，记录保存在当前设备的浏览器中，不会与朋友同步。
- 第十章进入世界档案馆，支持分类、搜索、详情和关联记录。
- `Esc` 关闭面板或打开目录，`H` 隐藏界面。声音默认关闭，可手动开启。
- 支持手机触摸操作、键盘操作与减少动态效果偏好。

## 十个章节

边界 → 被删除的地图 → 环极冰幕 → 第七远征队 → 无日之海 → 倒悬群岛 → 低语之森 → 苍白遗城 → 观测者 → 世界远未结束。

各章可通过独立地址访问，例如 `chapter/03/`；GitHub Pages 构建会生成十章入口，支持直接分享和刷新。

## 技术

React、Vite、GSAP ScrollTrigger、@gsap/react。React Bits 的 Magnet 与 Noise 用于克制的控件反馈和画面颗粒。素材随站点托管，没有外部图片热链。

```sh
npm install
npm run dev
npm run build
```

开发预览端口为5175。构建输出为 `dist/`，本地运行生产站点可执行 `npm start`。

## GitHub Pages

1. 将本项目提交至 `main`。
2. 在仓库 Settings → Pages → Build and deployment 中，将 Source 设为 **GitHub Actions**。
3. `.github/workflows/pages.yml` 会自动测试、构建并发布。之后每次推送至 `main` 都会更新网站。

`PAGES_BASE` 自动使用仓库名设置资源路径。仓库改名后，重新运行工作流即可。

## 当前范围

十章交互叙事及档案馆可运行。场景采用图像与矢量分层，图像实际尺寸为1672×941，并非原生4K或完整实时三维世界。浏览器功能检查覆盖十章工具、直达路由、滚动回退、档案检索及手机交互。
